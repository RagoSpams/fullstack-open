# Exercise 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save
    Note right of browser: JS prevents default form submission (e.preventDefault())
    Note right of browser: JS adds note to local array and re-renders UI instantly

    browser->>server: POST [https://studies.cs.helsinki.fi/exampleapp/new_note_spa](https://studies.cs.helsinki.fi/exampleapp/new_note_spa)
    activate server
    Note over server: Payload sent as JSON: { "content": "...", "date": "..." }
    server-->>browser: HTTP 201 Created
    deactivate server
```
